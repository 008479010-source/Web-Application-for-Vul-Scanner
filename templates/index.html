Scope & Authorization

Every scan is tied to a documented engagement record — required before any scan can run. This tool runs active, intrusive vulnerability scans (nmap NSE vuln scripts, nikto) — your authorization must specifically cover active vulnerability scanning, not just reconnaissance. Only test systems you own or have explicit written authorization to test (see README for the full legal/ethics policy: CFAA, GDPR, HIPAA, PCI DSS and related considerations).

2

Configure & Run Scan

Pick a single target or upload a batch, choose which scan modules to run, then start the scan.

This is active scanning, not passive recon. The NSE vuln-script and nikto modules send real probes designed to trigger and detect vulnerabilities — they are noisy, may appear in the target's own logs/IDS, and in rare cases can affect fragile services. CVE matches are candidate matches from a free-text NVD search and require human verification.
